# IBM Data Engineering - Coursera Practice

Repository lưu trữ mã nguồn và bài tập thực hành trong quá trình học chương trình IBM Data Engineering Professional Certificate trên Coursera.

Lưu ý: Repository này không chứa đầy đủ toàn bộ bài học vì phần lớn bài lab được thực hiện trực tiếp trên môi trường web của IBM (IBM Skills Network Labs). Mã nguồn ở đây chủ yếu là các bài tự viết lại để luyện tay và lưu trữ cá nhân.

## Cấu trúc thư mục

### coursera/

- 2 (Python for Data Science, AI & Development):
  - Thao tác với mảng và bảng dữ liệu: NumPy (1D, 2D), Pandas.
  - Xử lý chuỗi và biểu thức chính quy (RegEx).
  - Làm việc với file và định dạng dữ liệu: CSV, JSON, XML, Excel.
  - Thu thập dữ liệu web (Web Scraping) và gọi API: Requests, BeautifulSoup, Selenium.

- 3 (Python Project for Data Engineering):
  - Xây dựng quy trình ETL cơ bản: Trích xuất dữ liệu từ nhiều nguồn (CSV, JSON, XML), làm sạch/chuyển đổi, ghi log và lưu trữ vào database hoặc file CSV.
  - Web scraping và tự động hóa: Thu thập dữ liệu các bộ phim, GDP các quốc gia.
  - Dự án cuối khóa (banks_project): Thu thập danh sách các ngân hàng lớn nhất thế giới theo vốn hóa, chuyển đổi tỷ giá ngoại tệ, lưu vào cơ sở dữ liệu SQLite và xuất file CSV.

- 5 (Databases and SQL for Data Science with Python):
  - Cú pháp SQL từ cơ bản đến nâng cao: DDL, DML, sắp xếp (ORDER BY), gom nhóm (GROUP BY), tìm kiếm theo mẫu chuỗi.
  - Làm việc với cơ sở dữ liệu bằng Python: Kết nối SQLite qua thư viện sqlite3 và sử dụng ipython-sql (SQL magic).
  - Thực hành phân tích dữ liệu thực tế và hoàn thành dự án cuối khóa của học phần cơ sở dữ liệu.

### test/

- Thư mục bài tập tự luyện ngoài khóa học: Thực hành xử lý dữ liệu điểm thi với Pandas và nạp dữ liệu vào cơ sở dữ liệu SQLite.

### Chứng chỉ đính kèm

Các chứng chỉ thành phần của chương trình đã hoàn thành:
- Course 1: Introduction to Data Engineering
- Course 2: Python for Data Science, AI & Development
- Course 3: Python Project for Data Engineering
- Course 5: Databases and SQL for Data Science with Python

## Công nghệ sử dụng

- Ngôn ngữ: Python, SQL
- Thư viện và công cụ: Pandas, NumPy, BeautifulSoup4, Requests, Selenium, SQLite3, ipython-sql
- Cơ sở dữ liệu: SQLite
